# 🏃‍♂️ Radio Timer | 无线激光体能计时系统

![MCU](https://img.shields.io/badge/MCU-STM32F103C8T6-blue.svg)
![Framework](https://img.shields.io/badge/Framework-STM32%20HAL-brightgreen.svg)
![Communication](https://img.shields.io/badge/Wireless-NRF24L01+-orange.svg)
![Build](https://img.shields.io/badge/Build-Keil%20MDK-red.svg)

基于 **STM32F103** 搭配 **NRF24L01+** 2.4G 无线模块构建的高精度双节点（起点-终点）无线计时系统。通过激光传感器精准捕捉触发瞬间，完美适用于田径短跑、体能测试、无人机/小车竞速等需要高精度计时的场景。

---

## ✨ 核心特性

- 🚀 **精准触发**：采用激光对射传感器作为起终点触发源，硬件级边缘检测，杜绝人工掐表误差。
- 📡 **稳定无线通信**：基于 NRF24L01+ 模块实现起点与终点之间的低延迟无线信号同步。
- ⏱️ **毫秒级精度**：使用 STM32 硬件定时器（TIM）进行时基管理，确保极高的时间精度。
- 📺 **直观数据展示**：集成 0.96寸 OLED 屏幕，实时刷新计时数据及节点状态。
- 🔊 **语音反馈**：支持外接音频模块播放 MP3 提示音（如“准备”、“开始”、“冲线”等）。

---

## 🏗️ 系统架构与原理解析

系统在物理上分为两个独立节点，协同完成一次完整的计时闭环：

1. **🚩 Start Node (起点端)**
   - 部署于起跑线。
   - 实时监测起点激光传感器的状态。
   - 当检测到遮挡（起跑）时，立即通过 SPI 控制 NRF24L01 模块向终点端发送包含触发时间戳的启动数据包。

2. **🏁 Finish Node (终点端)**
   - 部署于终点线，作为系统的“主控与显示中心”。
   - **监听**：持续监听来自起点端的无线起跑信号。
   - **计时**：收到信号后，内部硬件定时器开始计时，并在 OLED 屏幕上动态刷新。
   - **结算**：当检测到终点激光传感器被触发时，停止计时，锁定最终成绩，并触发相应的音频播报。
